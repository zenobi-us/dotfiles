The decision

Keep the comment close, not the form heavy.

Recommendation: A, near the pin. It preserves the connection between the marked area and your words. B keeps the image unobstructed at the cost of width; C gives a predictable typing position but can cover the lower screenshot. On narrow screens, all three use a floating bottom card.

Same in all three: real native screenshot library, boxes and point pins, labelled coloured priority badges, edit/delete/undo, draft recovery, local persistence and JSON export. Empty comments show an error; unfinished drafts block export rather than silently dropping feedback. No user feedback is pre-filled.

Scope: medium-fidelity, interactive stateful-flow preview of the report’s feedback UI. It does not change the extension or the existing report. This is not a TUI simulation: the terminal images are the existing native PNGs. No multi-user sync, server submission, annotation resizing by pointer, or dense-pin collision handling is claimed. Export includes source-image hashes and original-pixel coordinates.
