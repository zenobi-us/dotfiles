# Only power weapons take a muzzle, so "I want a silenced X" is a class question first

**A suppressor is a muzzle attachment, and only power-type weapons have a muzzle
slot.** Tech weapons and smart weapons do not have one, so no attachment can make
them quiet. This is not a rarity thing, a level thing or a perk thing - the slot
is absent.

That turns a common request into a two-step question. "Can I run a silenced
Arasaka pistol" is really: *which class is that weapon, and does the class have
the slot?*

## Worked example: the Arasaka pistols

| weapon | class | takes a muzzle |
|---|---|---|
| **Tamayura** | power | yes |
| **Kenshin** | tech | no |
| **Yukimura** | smart | no |
| **Kappa** | smart | no |

The **Tamayura** is the answer to "a suppressed Arasaka pistol". It is a power
pistol, it takes a muzzle, and it is **still standard issue despite being
outdated** - which is a genuinely useful piece of characterisation on its own. An
Arasaka employee carrying one is carrying the thing the company hands out, not
the thing they chose.

The other three are the whole reason the question needed asking. Three Arasaka
pistols, none of which can be suppressed by attachment, and nothing in the
inventory UI explains why the option is missing - the slot simply is not there.

## Integrated suppression is a different category

Some weapons are **silent by construction** rather than by attachment. They carry
their suppression as part of the weapon and expose no muzzle slot to fill.

This matters because it is the **only silent option in a class that blocks
muzzles**. If a build needs a quiet weapon of a particular class, the search is
not "which suppressor fits" - it is "does a weapon in this class ship integrated
suppression."

Keep the two categories apart when answering. "It is silenced" is ambiguous
between them, and the two have opposite implications for what else can go in the
weapon.

## How to check rather than trust this table

Open the weapon in the inventory and look for the muzzle slot. Present or absent,
and it takes seconds. That is a better habit than memorising a table, because a
table is a snapshot and the mod slots on a specific weapon are exactly the kind
of detail a content patch adjusts.

## Where this comes up in character work

Constantly, and usually indirectly. A stealth-shaped V, an assassin concept, a
corpo who "carries the company sidearm" - all of them run into this, and the
answer changes what the character can actually be seen doing. It is one of the
few places where a build fact directly constrains a fiction.

## Scope

Read off weapon stats and mod slots in game on patch 2.31. Re-check the specific
weapons after a content patch; the class rule is the durable part.
