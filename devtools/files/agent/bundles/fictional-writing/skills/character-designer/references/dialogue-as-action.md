# Dialogue as Action

Treat dialogue as an attempt to change another person's behavior, knowledge, status, or choice.

## Rules

- Give each speaker an agenda.
- Ask what the speaker wants to accomplish.
- Make the exchange contain pressure or conflict.
- Do not use dialogue only to transfer information.
- Let spoken words differ from indirect thought when this reveals pressure.
- Change speech for status, trust, fear, anger, shame, and authority.
- Give each important character a distinct rhythm and vocabulary.
- Use physical action during dialogue when it supports the speaker's intent.
- Avoid predictable direct answers.
- Use silence, evasion, lies, and interruption as actions.

Dialogue can wander, but each exchange must affect the scene.

## Router trigger

Use this reference when characters sound alike, dialogue explains too much, or a conversation has no conflict.
