# Local Markdown tracker

## Collections

- [Tickets](tickets/): Store one Markdown file per stable ticket ID.
- [Initiatives](initiatives/): Store one directory per initiative, with an index that links its records.

## Operations

Read the [tracker configuration](../docs/agents/issue-tracker.md) before ticket work. Use the `reading-and-writing-tickets` skill for ticket operations. Resolve paths through the shared-context CLI.

Read the [triage labels](../docs/agents/triage-labels.md) before changing ticket readiness. Keep `triage` separate from `work_status`.
