Manage the Windows Alacritty release and bundled terminal themes.

For Dotfiles users. Updated 2026-11-27.

The module installs the GitHub Windows release and links its directory under AppData/Roaming/alacritty. The supplied file is named alacritty.windows.toml, not alacritty.toml. Do not assume automatic discovery; explicitly select the file when inspecting this configuration.
