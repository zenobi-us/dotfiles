# Deskflow server configuration

Share a Deskflow server configuration across Unix and Windows.

For Dotfiles users. Updated 2026-11-27.

The module links its configuration directory to ~/.config/deskflow on Unix and AppData/Roaming/deskflow on Windows. It supplies server.conf but does not install or start Deskflow. Review screen names, layout, and network trust locally before use.
