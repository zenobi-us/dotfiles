# Review a Deskflow screen layout

For Dotfiles users. Updated 2026-11-27.

## Result

Share a Deskflow server configuration across Unix and Windows.

## Prerequisites

Deskflow installed separately, trusted machines, and a backup of existing server configuration.

## Steps

1. Review server.conf locally and match its screen names to your machines.
2. Check the configured directory link for your platform.
3. Select the reviewed server.conf in Deskflow’s server configuration controls before starting sharing.

## Verification

Only intended screens connect and pointer movement follows the reviewed adjacency. No connection is implied by installing files.

## Recovery

Stop sharing if an unexpected screen connects. Restore the previous configuration and review pairing, encryption, and network access.
