## Module configuration

[The tool declaration](../../mise.toml) requests `aqua:tree-sitter/tree-sitter` at `latest`. `latest` tracks the newest available release when resolved.

The aqua backend installs tree-sitter/tree-sitter. Language grammars and generated parsers are not supplied by this module.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
