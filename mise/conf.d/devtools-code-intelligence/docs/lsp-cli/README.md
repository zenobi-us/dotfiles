Run language-server diagnostics from the command line.

## Module configuration

[The tool declaration](../../mise.toml) requests `github:valentjn/lsp-cli` at `latest`. `latest` tracks the newest available release when resolved.

The installed help requires --server-command-line and accepts file or directory paths. A compatible language server must be supplied separately.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
