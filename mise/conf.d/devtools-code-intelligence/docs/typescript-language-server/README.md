Provide TypeScript and JavaScript editor language services.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:typescript-language-server` at `latest`. `latest` tracks the newest available release when resolved.

The npm package is installed without an editor client configuration. The module does not declare the typescript npm package itself.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
