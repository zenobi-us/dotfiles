# Review workspace preferences

For Dotfiles users. Updated 2026-11-27.

## Result

Provide the MonoSlate theme, preferences, and zenobius layout.

## Prerequisites

Herdr App and a backup of current user preferences.

## Steps

1. Inspect the supplied theme, layout, fonts, keys, and programs files locally.
2. Check their configured destinations in mise.toml.
3. Apply the normal dotfiles bootstrap, then select the layout and theme in Herdr App.

## Verification

The selected layout mounts the intended mods and displays readable text with available fonts.

## Recovery

Restore previous preferences or choose the previous layout if keybindings or programs do not suit the machine.
