# Equalise panes mod

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Restore equal pane dimensions after splits and closes.

For Dotfiles users. Updated 2026-11-27.

The mod equalises widths and heights after pane topology changes. Manual resizing remains until the next pane change. The manual action is equalise-panes.equalize; the manifest documents Ctrl+Alt+E and requires Bun and hc.
