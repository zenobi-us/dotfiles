# Shared Context tab strip

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Provide space-local panel selection and tab controls for Herdr App.

For Dotfiles users. Updated 2026-11-27.

The custom tab strip remembers panel selection per space, includes Files/Changes/Shared context controls, and exposes Equalise. Tab controls select, rename, move, and close tabs. The manifest uses place=none and needs the supplied layout.
