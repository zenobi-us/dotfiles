# Inspect the Shared Context panel

For Dotfiles users. Updated 2026-11-27.

## Result

Browse repository context, tracker records, and workflow activity in Herdr App.

## Prerequisites

Herdr App, Bun, the context helper, and an aligned repository. Use a non-sensitive repository for captures.

## Steps

1. Check that ~/.config/herdr-app/mods/shared-context resolves to this directory.
2. Load the supplied zenobius layout through Herdr App’s layout controls.
3. Select Shared context and choose the intended repository before browsing records.

## Verification

The panel shows the expected repository or an explicit query error; changing repositories refreshes the displayed context.

## Recovery

Return to the prior layout if the panel is unavailable. Check the helper and target permissions before altering records.
