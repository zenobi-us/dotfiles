Browse repository context, tracker records, and workflow activity in Herdr App.

For Dotfiles users. Updated 2026-11-27.

The mod retains context/tracker views, fetches target-side query results, and displays repository records and workflow activity. Its manifest uses place=none; the supplied layout must mount it. Configuration links do not install Herdr App.
