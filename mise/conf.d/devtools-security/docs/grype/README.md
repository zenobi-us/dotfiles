## Module configuration

[The tool declaration](../../mise.toml) requests `grype` at `latest`. `latest` tracks the newest available release when resolved.

The module installs Grype without scan targets or a scheduled scan. Vulnerability databases and findings require separate handling.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
