# Ghostty terminal configuration

Link Ghostty configuration and local themes on Unix.

For Dotfiles users. Updated 2026-11-27.

The module links the whole directory into ~/.config/ghostty. The config uses JetBrainsMono Nerd Font Mono, block cursor, undecorated windows, and explicit keybindings. It does not install Ghostty.
