# Review the Ghostty configuration

For Dotfiles users. Updated 2026-11-27.

## Result

Link Ghostty configuration and local themes on Unix.

## Prerequisites

Ghostty installed separately and the configured font available.

## Steps

1. Back up any existing ~/.config/ghostty before replacing its link.
2. Review config and the theme names in this module.
3. After normal dotfiles bootstrap, start a new Ghostty window or reload its configuration.

## Verification

The expected font, cursor, theme, and keybindings appear without configuration errors.

## Recovery

Restore the previous directory link if Ghostty rejects an option. Use the shader manager’s separate guide for shader changes.
