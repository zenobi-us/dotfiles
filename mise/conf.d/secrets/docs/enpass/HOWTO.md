# Inspect Enpass installation request

For Dotfiles users. Updated 2026-11-27.

## Result

Request Enpass through platform package bootstrap.

## Prerequisites

A supported Linux dnf or Windows Scoop environment and access to the configured package source.

## Steps

1. Review the package declaration for your platform.
2. Confirm the Enpass package source is available through your normal package workflow.
3. After approved package bootstrap, open Enpass without replacing an existing vault.

## Verification

Enpass starts and offers your expected vault selection or setup flow. Installation is not proof of vault access.

## Recovery

Cancel setup if the wrong vault is selected. Preserve backups and recovery keys outside this repository.
