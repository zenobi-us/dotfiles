# Creative assets

Diagram, image, poster, and ComfyUI tooling.

## Notable items

- **[D2](docs/d2/README.md):** Create diagrams from text descriptions.

- **[Artem](docs/artem/README.md):** Convert images into terminal-friendly ASCII art.

- **[Takumi](docs/takumi/README.md):** Render images, animations, and SVG from JSX, HTML, and CSS.

- **[Poster](docs/poster/README.md):** Create distributable React posters from a single TSX file.

- **[Comfy CLI](docs/comfy-cli/README.md):** Manage ComfyUI environments and workflow operations.


## Scope

[mise.toml](mise.toml) is the source of truth for versions and backend options. These declarations install tools; they do not activate editor clients, provision accounts, or start services. `latest` is a moving request, not a fixed version.

Choose an item above for its configuration and installation guide. Module inclusion in your active mise configuration is separate from the explicit installation commands in these guides.
