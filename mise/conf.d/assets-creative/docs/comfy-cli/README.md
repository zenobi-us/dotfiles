## Module configuration

[The tool declaration](../../mise.toml) requests `pipx:comfy-cli` at `latest`. `latest` tracks the newest available release when resolved.

The pipx package provides comfy. Installing the CLI does not install ComfyUI, model weights, custom nodes, or cloud credentials.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
