Create distributable React posters from a single TSX file.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:poster-ai` at `0.5.0`. `0.5.0` is the configured version pin.

The poster-ai package provides the poster executable and is pinned to 0.5.0. The module supplies no poster source files.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
