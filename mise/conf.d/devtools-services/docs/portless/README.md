# Portless

<!-- Add a real, redacted terminal capture or diagram with descriptive alt text and a caption showing this tool in use. -->

Give development servers stable named localhost URLs.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:portless` at `latest`. `latest` tracks the newest available release when resolved.

The installed help requires Node.js 24 or newer, while devtools-runtimes requests Node.js 22. Resolve that mismatch before running Portless. Proxy startup may elevate privileges and install a local CA.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
