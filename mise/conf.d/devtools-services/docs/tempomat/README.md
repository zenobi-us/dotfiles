Access Tempo.io cloud services from the command line.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:tempomat` at `latest`. `latest` tracks the newest available release when resolved.

The npm package provides the tempo executable. Despite its module location, it is a Tempo.io cloud CLI, not a local service supervisor. Authentication is not configured here.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
