Serve static files with a small HTTP server.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:serve` at `latest`. `latest` tracks the newest available release when resolved.

The npm package is installed without a document root or bind address. Review the network listener before exposing private files.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
