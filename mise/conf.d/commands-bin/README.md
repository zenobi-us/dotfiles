# Local commands

Expose standalone utility commands through ~/.local/bin on Unix.

For Dotfiles users. Updated 2026-11-27.

## Notable items

- **[Project mise bootstrap copier](docs/add-mise/README.md)** — Copy the bundled mise installer into the current project.
- **[Legacy Android SDK helper](docs/androiddev/README.md)** — Provide legacy Android SDK installation and AVD creation routines.
- **[Browser debug bridge](docs/devtool/README.md)** — Pass the first local Chrome debug target to bdg.
- **[Docker-OSX launcher](docs/docker-osx/README.md)** — Launch the configured Sonoma Docker-OSX container.
- **[Directory gallery](docs/gallery/README.md)** — Serve the current directory as an image gallery and file browser.
- **[Ghostty shader manager](docs/ghostty-shaders/README.md)** — Manage shader sources and apply Ghostty shader selections.
- **[LoRA organiser](docs/lora-organise/README.md)** — Review metadata-based LoRA move plans before explicit application.
- **[Markdown viewer](docs/markdown-view/README.md)** — Serve one Markdown document on a loopback HTTP listener.
- **[Samba container launcher](docs/samba-here/README.md)** — Provide a Docker-based directory-sharing launcher for inspection.
- **[ZeroTier DNS join helper](docs/zerotier-join/README.md)** — Join a ZeroTier network and configure its split DNS with systemd-resolved.
- **[Enpass export merger](../devtools-enpass-merge/docs/enpass-merge/README.md)** — Forward to the canonical Enpass export merger.
