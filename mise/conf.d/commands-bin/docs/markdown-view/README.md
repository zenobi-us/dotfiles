# Markdown viewer

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Serve one Markdown document on a loopback HTTP listener.

For Dotfiles users. Updated 2026-11-27.

The command binds 127.0.0.1 and chooses a free port unless --port is supplied. It serves supported images within the document directory. Frontmatter can load exact-version npm plugins, so only render trusted documents.
