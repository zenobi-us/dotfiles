# Ghostty shader manager

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Manage shader sources and apply Ghostty shader selections.

For Dotfiles users. Updated 2026-11-27.

The command supports an interactive picker, list, add, apply, clear, and favorites. It stores sources under the XDG data directory and edits the Ghostty config. Gum and Ghostty are required; automatic reload is platform-dependent.
