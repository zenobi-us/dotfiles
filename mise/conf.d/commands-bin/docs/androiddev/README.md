# Legacy Android SDK helper

Provide legacy Android SDK installation and AVD creation routines.

For Dotfiles users. Updated 2026-11-27.

This helper dispatches `install`, `create`, and `reset`. Installation downloads archives and edits a shell profile. It still calls the legacy `android update sdk` command. Treat it as legacy source, not a verified modern SDK installer.
