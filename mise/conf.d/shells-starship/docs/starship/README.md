# Starship prompt

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Manage Starship and its text-based prompt symbols.

For Dotfiles users. Updated 2026-11-27.

The module requests `starship` through mise. The module copies starship.toml into ~/.config; Windows also copies it under AppData/Roaming. Symbols use plain labels for many language modules. Shell initialisation belongs to the shell module, not this file alone.

The declaration controls installation; it does not configure accounts or prove that the executable is installed.
