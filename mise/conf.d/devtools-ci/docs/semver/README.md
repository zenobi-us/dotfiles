Evaluate and manipulate semantic versions from the command line.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:semver` at `latest`. `latest` tracks the newest available release when resolved.

This module installs the npm semver package; it does not define release rules or publish packages.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
