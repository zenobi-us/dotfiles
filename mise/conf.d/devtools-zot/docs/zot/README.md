Manage Zot with local themes and linked agent extensions.

For Dotfiles users. Updated 2026-11-27.

The module requests `zot` through mise. The tool alias resolves to github:patriceckhart/zot. config.json selects a provider/model and Rose Pine theme; availability depends on separately configured accounts. The module links themes and clones extension repositories.

The declaration controls installation; it does not configure accounts or prove that the executable is installed.
