## Module configuration

[The tool declaration](../../mise.toml) requests `cmake` at `latest`. `latest` tracks the newest available release when resolved.

The module installs CMake; project generators, compilers, and build directories are configured by each project.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
