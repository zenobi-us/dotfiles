## Module configuration

[The tool declaration](../../mise.toml) requests `watchexec` at `latest`. `latest` tracks the newest available release when resolved.

The module installs the watcher without defining watched paths or commands. Choose a non-destructive command before starting a watcher.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
