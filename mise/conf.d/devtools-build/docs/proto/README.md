Manage project toolchains with moonrepo Proto.

## Module configuration

[The tool declaration](../../mise.toml) requests `github:moonrepo/proto` at `latest`. `latest` tracks the newest available release when resolved.

The module installs moonrepo/proto alongside mise. It does not configure a Proto toolchain or migrate mise versions.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.

## Get started

Use the [installation and inspection guide](HOWTO.md) to install the declared version without editing the module.
