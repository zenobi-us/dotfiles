Manage Lazygit with automatic fetch and main-branch forwarding.

For Dotfiles users. Updated 2026-11-27.

The module requests `lazygit` through mise. config.yml enables autoFetch, limits forwarding to main/master, and sets fetchInterval to 380 seconds. The existing module README remains preserved; its five-minute statement does not match the current 380-second source.

The declaration controls installation; it does not configure accounts or prove that the executable is installed.
