Provide reusable repository settings and default-branch ruleset JSON.

For Dotfiles users. Updated 2026-11-27.

Settings allow squash/rebase merges, disable merge commits, and delete merged branches. The ruleset requires resolved review threads and a test check, but zero approving reviews. A repository-role bypass is configured. These templates do not prove applied remote policy.
