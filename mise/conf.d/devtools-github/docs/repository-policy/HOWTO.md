# Review repository policy

For Dotfiles users. Updated 2026-11-27.

## Result

Provide reusable repository settings and default-branch ruleset JSON.

## Prerequisites

Target repository settings access and ruleset administration permission.

## Steps

1. Compare both JSON files with the existing remote settings.
2. Confirm the required check is actually named test and review the role bypass.
3. Apply only reviewed settings through your approved workflow. This module declares no bootstrap task.

## Verification

Remote settings show the intended methods and protection; local files alone do not establish enforcement.

## Recovery

Export current remote settings before changes and restore them if a mismatched check blocks work.
