## Module configuration

[The tool declaration](../../mise.toml) requests `terraform` at `latest`. `latest` tracks the newest available release when resolved.

The module installs Terraform without providers, backend state, or cloud authentication. Installation alone does not authorize infrastructure changes.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
