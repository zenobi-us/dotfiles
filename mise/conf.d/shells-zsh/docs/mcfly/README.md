# McFly history search

<!-- Add a real screenshot with descriptive alt text and a caption, or a redacted terminal capture/diagram for this headless capability. -->

Initialise McFly history search in interactive Zsh.

For Dotfiles users. Updated 2026-11-27.

Mise requests github:cantino/mcfly. The active interactive module evaluates mcfly init zsh. Zsh separately shares history, ignores duplicate entries, and stores 1,000 entries in ~/.zsh_history. History can contain secrets.
