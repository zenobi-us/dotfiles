# Inspect the assume alias

For Dotfiles users. Updated 2026-11-27.

## Result

Source assume and add Granted completion directories to Zsh.

## Prerequisites

Granted installed separately and the managed shell.

## Steps

1. Run `type assume` and confirm the source-style alias.
2. Check that the ~/.granted completion directories exist.
3. Review your installed Granted help before selecting any AWS profile.

## Verification

The alias resolves to the installed Granted script and completion paths are present. Account access is not established by an alias.

## Recovery

Open a fresh shell to discard unintended environment changes. Keep account identifiers out of screenshots.
