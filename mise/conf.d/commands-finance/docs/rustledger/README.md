## Module configuration

[The tool declaration](../../mise.toml) requests `github:rustledger/rustledger` at `0.21.0`. `0.21.0` is the configured version pin.

The upstream rustledger release is pinned to 0.21.0. The upstream CLI is rledger; this module supplies no ledgers, financial records, or account settings.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
