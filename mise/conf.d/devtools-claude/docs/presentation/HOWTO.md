# Review Claude presentation files

For Dotfiles users. Updated 2026-11-27.

## Result

Provide local themes and authored response styles for Claude.

## Prerequisites

Claude with support for the configured presentation directories.

## Steps

1. Review the file names under themes/ and output-styles/.
2. Compare linked names under ~/.claude/themes and ~/.claude/output-styles.
3. Choose a style supported by your installed Claude version.

## Verification

The host offers the selected style and renders it legibly.

## Recovery

Return to the host default if a theme or style is unsupported.
