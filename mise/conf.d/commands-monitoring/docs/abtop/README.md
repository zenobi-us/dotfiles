Monitor local AI coding-agent sessions in a terminal interface.

## Module configuration

[The tool declaration](../../mise.toml) requests `github:graykode/abtop` at `latest`. `latest` tracks the newest available release when resolved.

The upstream project describes session, token, context, rate-limit, and port monitoring. The module only installs it; it does not install agent hooks or configure profiles. An interactive terminal is needed for the TUI.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
