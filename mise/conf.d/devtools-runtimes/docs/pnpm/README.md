Manage JavaScript workspace dependencies with pnpm.

## Module configuration

[The tool declaration](../../mise.toml) requests `pnpm` at `latest`. `latest` tracks the newest available release when resolved.

The module installs pnpm without enabling a workspace or selecting a project lockfile.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.

Use the [installation and inspection guide](HOWTO.md) to install the declared version without editing the module.
