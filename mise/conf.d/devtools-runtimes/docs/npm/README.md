Manage JavaScript packages with npm.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm` at `latest`. `latest` tracks the newest available release when resolved.

npm is declared independently from Node.js. The module supplies no registry authentication or project lockfiles.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
