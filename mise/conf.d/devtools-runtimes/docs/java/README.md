## Module configuration

[The tool declaration](../../mise.toml) requests `java` at `latest`. `latest` tracks the newest available release when resolved.

The module requests latest without selecting a vendor or defining application JVM options.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
