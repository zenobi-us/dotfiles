## Module configuration

[The tool declaration](../../mise.toml) requests `node` at `22`. `22` selects the Node.js 22 release line.

The module requests the Node.js 22 major release line. A project can select a different runtime through its own configuration.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
