# Development runtimes

Language runtimes, SDKs, and package managers.

## Notable items

- **[Bun](docs/bun/README.md):** Run JavaScript and TypeScript with the Bun toolkit.

- **[Deno](docs/deno/README.md):** Run JavaScript and TypeScript with Deno.

- **[.NET SDK](docs/dotnet/README.md):** Develop and run .NET applications.

- **[Go](docs/golang/README.md):** Build and run Go programs.

- **[Java](docs/java/README.md):** Run Java applications and Java development tools.

- **[Lua](docs/lua/README.md):** Run Lua programs.

- **[Node.js](docs/node/README.md):** Run server-side JavaScript programs.

- **[npm](docs/npm/README.md):** Manage JavaScript packages with npm.

- **[PDM](docs/pdm/README.md):** Manage Python project environments and dependencies.

- **[pnpm](docs/pnpm/README.md):** Manage JavaScript workspace dependencies with pnpm.

- **[Python](docs/python/README.md):** Run Python programs.

- **[Rust](docs/rust/README.md):** Develop Rust applications with the Rust toolchain.

- **[uv](docs/uv/README.md):** Manage Python packages, environments, and tool execution.

- **[Yarn](docs/yarn/README.md):** Manage JavaScript project dependencies with Yarn.

- **[Zig](docs/zig/README.md):** Develop software with the Zig compiler and toolkit.

- **[Pkl](docs/pkl/README.md):** Evaluate configuration expressed in the Pkl language.


## Scope

[mise.toml](mise.toml) is the source of truth for versions and backend options. These declarations install tools; they do not activate editor clients, provision accounts, or start services. `latest` is a moving request, not a fixed version.

Choose an item above for its configuration and installation guide. Module inclusion in your active mise configuration is separate from the explicit installation commands in these guides.
