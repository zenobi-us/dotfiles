Expose Chrome debugging and automation through an MCP server.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:chrome-devtools-mcp` at `latest`. `latest` tracks the newest available release when resolved.

Installing the npm package does not register it with an MCP client or launch a browser. Configure the client separately.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.

## Get started

Use the [installation and inspection guide](HOWTO.md) to install the declared version without editing the module.
