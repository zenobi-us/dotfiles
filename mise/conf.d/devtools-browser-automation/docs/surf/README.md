Automate browser interactions from the command line.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:surf-cli` at `latest`. `latest` tracks the newest available release when resolved.

The surf-cli npm declaration allows low-download packages with allow_low_downloads = true. This exception applies to installation, not browser permissions or session access.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
