Expose Firefox debugging and automation through an MCP server.

## Module configuration

[The tool declaration](../../mise.toml) requests `npm:firefox-devtools-mcp` at `latest`. `latest` tracks the newest available release when resolved.

Installing the npm package does not configure Firefox remote debugging or register an MCP client.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.

Use the [installation and inspection guide](HOWTO.md) to install the declared version without editing the module.
