---
title: Author a skill with artifact contracts
---

1. Ask your agent to use `writing-skills` for the target skill. Existing `writing-great-skills` invocations route there too.
2. Give the agent the intended behavior, artifact consumers and authoritative owner definitions. Let it identify missing authority before declaring support.
3. Check the artifact inventory, including external formats and prose or opaque-asset exclusions. Check independent inputs and outputs in `contracts.json`.
4. Inspect the baseline and pressure outcomes. Require public owner commands, persisted data and unchanged bytes for rejected conversions.
5. Resolve reported blockers before deployment. Permit automatic conversion only within an otherwise authorized mutation; select bulk upgrades explicitly.
