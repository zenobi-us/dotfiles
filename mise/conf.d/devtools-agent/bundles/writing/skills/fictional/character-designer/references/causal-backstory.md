# Causal Backstory

Use backstory to explain present behavior and choices.

## Causal chain

```text
formative event
→ character interpretation
→ belief or false belief
→ coping behavior
→ present want
→ inciting pressure
→ choice under pressure
→ change, failure, or confirmation
```

## Design rules

- State what happened.
- State what the character thinks happened.
- State what the character learned.
- State how that lesson affects present behavior.
- State what the character wants now.
- State what the character needs for a meaningful arc.
- State what the character fears losing.
- State the choice that tests the belief.

The formative event can be small. It must explain a present pattern.

Separate the event from the character's interpretation. The interpretation can be false, incomplete, or contested.

Do not write a biography that does not affect a reaction, choice, relationship, or cost.

## Router trigger

Use this reference when a character feels flat, reacts without a clear cause, or lacks a personal arc.
