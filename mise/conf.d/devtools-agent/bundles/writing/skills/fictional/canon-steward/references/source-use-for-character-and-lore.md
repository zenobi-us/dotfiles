# Source Use for Character and Lore

Use external sources to support facts. Do not copy source text into project files.

## Rules

- Record the source title, publisher, URL or filename, and access date.
- Record a page, section, or URL locator when available.
- Write source claims as short paraphrases.
- Separate source fact from project interpretation.
- Mark original additions as original.
- Mark weak evidence as unverified.
- Keep conflicting claims visible.
- Record which character, faction, place, event, or story uses each claim.
- Use official material to support story pressure, not to replace original writing.
- Do not create a plain-text copy of an official book, webpage, adventure, or background story.

For character material, separate:

- Official history.
- Character interpretation.
- Project-created formative events.
- Unresolved or disputed facts.

## Router trigger

Use this reference when a character, faction, place, event, or story uses official or licensed setting material.
