# Dramatic Tension

Dramatic tension comes from an expected result that remains uncertain.

## Build tension

- State what the character wants.
- State what the character expects.
- Give the opposing force a credible response.
- Remove a safe option.
- Increase the cost of delay.
- Reveal information that changes the meaning of the problem.
- Force a choice between important goals.
- Make each choice solve one problem and create another.

Use more than violence to raise pressure. Remove options, damage trust, expose secrets, change relationships, or increase obligations.

Track both reader expectations and character expectations. Break an expectation only when the result creates a new consequence.

Do not make every outcome surprising. Make the important outcome earned but uncertain.

## Router trigger

Use this reference when an arc feels flat, predictable, or low-stakes.
