# Character creation hands out 22 attribute points, and only 7 of them are yours to place

The arithmetic, in full:

```
5 attributes x 3 pre-placed   = 15   (the floor; cannot be lowered)
free points to distribute     =  7
                               ----
total on the sheet at creation = 22
```

Verified in game on the 2.3 patch line (reported as 2.3.1), after an assistant was
told explicitly not to answer this one from memory.

## Why the question gets two different right answers

Ask "how many attribute points do I get at character creation" and both **22** and
**7** are defensible, because they answer different questions:

- **22** is what the character sheet totals when the creator opens.
- **7** is what the player actually decides.

Somebody planning a build wants the second number. Somebody comparing this game to
another wants the first. Quoting one without saying which is which is how a player
ends up planning around fourteen points that were never theirs.

**The useful formulation is both, in one sentence:** *three are already in each
attribute, and you place seven more.*

## What it constrains

With 7 free points, no concept can start with more than one attribute meaningfully
ahead of the rest - a single attribute taken high consumes most of the allocation.
This is the real reason "my V is a top-tier netrunner and a top-tier solo from day
one" is not a starting build: not a rule forbidding it, just an allocation that
does not stretch. It is the mechanical companion to
[why a veteran starts at level one](/canon/why-a-veteran-starts-at-level-one) - the
prologue character is deliberately unfinished.

The floor of 3 is the other half of the constraint, and it is covered with the rest
of the build gating in
[Five attributes, an attribute floor, and the cyberware a stealth concept depends
on](/canon/the-build-facts-that-gate-a-concept): there is no zero, so points cannot
be reclaimed by dumping an attribute.

## This is a number, so re-read it after a patch

Attribute economy is exactly the class of value CDPR has moved before - the 2.0
rework changed attribute and perk maths substantially. A number quoted from memory
here is quoted from a build of the game that may no longer exist. Open the creator
and read it; it takes less time than justifying the recalled figure.

## Scope

Read off the character creator on the 2.3 line. Single reading, but of a number the
UI displays directly. A creation-overhaul mod changes it, and several do.
