# Terminal commands

File navigation, search, editing, and structured-data tools.

## Notable items

- **[fzf](docs/fzf/README.md):** Select entries with an interactive fuzzy finder.

- **[Glow](docs/glow/README.md):** Read Markdown in the terminal.

- **[jq](docs/jq/README.md):** Filter and transform JSON from the command line.

- **[Midnight Commander](docs/mc/README.md):** Browse and manage files in a terminal file manager.

- **[ripgrep](docs/ripgrep/README.md):** Search file contents with the rg command.

- **[yq](docs/yq/README.md):** Query and transform structured documents from the terminal.

- **[fd](docs/fd/README.md):** Find filesystem entries with a concise command-line interface.

- **[Micro](docs/micro/README.md):** Edit text files in a terminal editor.

- **[Neofetch](docs/neofetch/README.md):** Display system information beside terminal artwork.

- **[mq](docs/mq/README.md):** Query, transform, and render Markdown and structured data.


## Scope

[mise.toml](mise.toml) is the source of truth for versions and backend options. These declarations install tools; they do not activate editor clients, provision accounts, or start services. `latest` is a moving request, not a fixed version.

Choose an item above for its configuration and installation guide. Module inclusion in your active mise configuration is separate from the explicit installation commands in these guides.
