## Module configuration

[The tool declaration](../../mise.toml) requests `github:harehare/mq` at `latest`. `latest` tracks the newest available release when resolved.

The module installs harehare/mq. Repository Markdown operations also require the okf.mq import described in repository instructions; that policy is not a mise tool option.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
