Browse and manage files in a terminal file manager.

## Module configuration

[The tool declaration](../../mise.toml) requests `mc` at `latest`. `latest` tracks the newest available release when resolved.

The module installs mc without custom panels or key bindings. File operations can change or delete real files.

This module contains installation declarations only. It defines no custom commands, plugins, or runtime integrations for this item.
