---
title: Install mise
---

On Linux or macOS, install mise, open a new shell, and check its version. Review the installer before running it.

```
curl https://mise.run | sh
mise --version
```

On Windows, use `winget install --exact --id mise.run`. See the [Windows setup guide](https://github.com/zenobi-us/dotfiles/blob/master/README.md#windows) for required features and environment configuration.
