---
kind: tutorial
title: Make your first commit with the commit skill
---

1. Start Claude Code or OMP in a repository with uncommitted changes.
2. Type `/developer:commit` in Claude Code, or `/skill:commit` in OMP.
3. The agent prints a plan of atomic commits, then makes each commit with a Conventional Commit message.

The agent cannot invoke this skill by itself. Only you can start it.
