title: What developer is for
---

developer is the largest bundle. It holds the git workflow (commit, pull request, worktree and Worktrunk skills), browser and devtools skills, game development, shells and UI development, and the reviewer agents.

Worktrunk owns every git worktree. Skills call `wt`, never `git worktree`, so Worktrunk hooks run on each create, merge and remove.
