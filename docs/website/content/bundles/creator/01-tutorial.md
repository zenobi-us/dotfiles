---
kind: tutorial
title: Turn an answer into an HTML page
---

1. Start Claude Code or OMP after the bundles are installed.
2. Ask a question that needs a long answer, for example a comparison of two tools.
3. Type `/creator:html-artifact` in Claude Code, or `/skill:html-artifact` in OMP.
4. The agent writes the answer as a standalone HTML file instead of a long chat reply.
