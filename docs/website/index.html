01

Learning-oriented

Get started

Inspect first. Apply when the plan matches your machine.

Install mise

On Linux or macOS, install mise, open a new shell, and check its version. Review the installer before running it.

curl https://mise.run | sh
mise --version

On Windows, use winget install --exact --id mise.run. See the Windows setup guide for required features and environment configuration.

Inspect the configuration

Clone to the stable configuration path. These commands inspect the plan without applying it.

git clone https://github.com/zenobi-us/dotfiles.git \
  "$HOME/.local/share/dotfiles"
cd "$HOME/.local/share/dotfiles"
mise trust
mise bootstrap --dry-run

Use an existing checkout if that path is already present. Bootstrap can install packages and replace deployed configuration links; keep backups of your current setup.

Apply the reviewed plan

mise bootstrap --yes

On Linux and macOS, open a new Zsh process after shell files change: exec zsh. The managed .zshenv sets MISE_GLOBAL_CONFIG_ROOT for later bootstrap runs.

02

Task-oriented

How-to guides

Change only the part you need.

Refresh configuration links

Apply dotfiles without reinstalling every tool.

mise bootstrap --only dotfiles --yes

Install tools or refresh agent setup

mise bootstrap --only tools --yes
mise run bootstrap-agent

Check what is missing

mise bootstrap status
mise bootstrap status --missing
mise bootstrap plan

View a local Markdown file

markdown-view ./path/to/file.md

The command prints a local browser URL. Frontmatter plugins execute with your permissions; view only trusted files.
