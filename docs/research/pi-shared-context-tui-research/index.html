Preview boundaries

These are self-contained HTML simulations with synthetic ticket and receipt data. They do not write to a tracker, execute worktree commands, or open actual Pi sessions. Proposed native layouts remain unverified in Pi. JavaScript is required; the A–C page uses the browser’s gzip decompression API.

Serve from the repository root

serve -l tcp://127.0.0.1:4297 --no-port-switching --no-clipboard -c serve.json docs/research/pi-shared-context-tui-research

The configuration path is relative to the served directory. It disables caching. All example links are relative, so the collection also works when hosted under a subdirectory.
