Scope / rootsLocal initiative index links, GitHub spec/map sub-issues, or Jira epic children become roots. A linked member may also be another member’s blocker.Call these entry members, not dependency-free roots. Keep scope while drilling.


Containment--ticket discovers the containing initiative through membership / parent chains, then renders its member-root forest.parent is not blocked_by. A dependency-only node may not rediscover this initiative with --ticket; retain initiative context.


Edges / identityDirect blocker lists are deduplicated and sorted. Nodes are memoized by ID. Recursive blocker closure can include tickets not linked in this index.Derive Used by within this loaded graph, not all repository consumers. Never store a second blocks list. Keep a member/dependency-only badge.


Authoring constraintsreferences/tasks/create.md and update.md require uniquely resolved references, no self-link or cycle, and a real start-time dependency; completed blockers must not be kept open unnecessarily.Containment and convenient visual ordering do not justify an edge. Keep dependency editing separate from browsing; no drag-reorder operation should silently create blockers.


Dot-list projectionA repeated ticket row is printed again, but only its first occurrence expands. The current CLI does not annotate these as aliases.E adds explicit reference labels. Keep occurrence-path identity for focus, ticket ID / canonical ref for data and actions.


StatusAny non-empty blocker list prints WAITING, regardless of blocker completion. With no blockers, the formatter groups implemented, merged, and completed into COMPLETED.Show raw tracker state. W-50 still prints WAITING even though W-10 is completed. Do not reuse display labels as Start/Finish/Submit guards.


Invalid graphCycle, missing ticket, and provider-ID mismatch fail explicitly.Fail visibly, not a misleading partial or empty success. Retry retains the intended scope.


Refs and receiptsThe shared core Ticket contains ID, title, type, optional status. DependencyGraph contains roots, tickets, blockedBy; it does not contain canonical refs or receipt records.Retain adapter-resolved refs separately and join receipt data by canonical identity. Do not parse ASCII to rebuild the model.
