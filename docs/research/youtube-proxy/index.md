# Self-hosted YouTube ad and sponsor filtering gateways

## Goal

Find self-hosted projects that can provide a YouTube viewing gateway for users on a home network and remove or skip platform advertisements and creator-sponsored segments.

## Scope boundary

This is an initial candidate inventory only. No candidate has been researched or assessed in this document. Inclusion does not confirm that a project is active, self-hostable, suitable as a network gateway, or able to remove either type of advertising. Validate each point during later research.

## Candidate projects to research

### YouTube front ends and proxy services

- Invidious
- Piped
- ViewTube
- CloudTube
- FreeTube
- LibreTube
- NewPipe
- Grayjay
- youtube-local
- Youtube2JSON
- yt-proxy
- YouTube.js (Innertube client)

### Ad and sponsor filtering components

- SponsorBlock
- AdGuard Home
- Pi-hole
- Blocky
- Technitium DNS Server
- NextDNS (self-hosting and gateway fit to verify)

### Download, archive, or media-server projects to check for gateway fit

- yt-dlp
- Tube Archivist
- MeTube
- Pinchflat
- ytdl-sub
- Tubesync
- Tartube
- ytptube

## Questions for later research

- Which projects support self-hosted server deployment and concurrent household users?
- Which provide a gateway or browser-facing service rather than only a client, downloader, or archive?
- Which can remove platform-inserted advertisements, creator-sponsored segments, or both?
- Which work with standard YouTube URLs and common clients?
- What are the maintenance, privacy, security, reliability, and operational trade-offs?
- What account, API, legal, or service terms affect household use?

## Research status

Candidate discovery only. Do not treat this inventory as a recommendation or as evidence that any listed project meets the goal.
